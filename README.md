# Fade & Co. — Barbershop Portfolio

A dark, editorial barbershop showcase site built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.

## Features

- Scroll-driven scissors animation across the Services section
- Full booking form with calendar and time-slot availability
- Customer reviews marquee and testimonials section
- Masonry photo gallery
- Mobile-first responsive layout

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Hook Form + Zod

## Getting Started

```bash
npm install
npm run dev
```
